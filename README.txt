CLOUDFLARE PAGES — FREE HOSTING
1. Sign in to Cloudflare and open Workers & Pages.
2. Choose Create, then Pages, then Upload assets.
3. Name the project and upload the contents of this folder (or drag in the folder).
4. Choose Deploy. Cloudflare will provide a free pages.dev address.
5. Open the Pages project's Custom domains section and choose Set up a custom domain.
6. Enter protecfiresafety.co.uk and follow Cloudflare's DNS prompts. Repeat for www.protecfiresafety.co.uk if you want both versions to work.
7. Future changes can be deployed by creating a new deployment and uploading the updated files.

GITHUB PAGES — FREE HOSTING
1. Create a new public GitHub repository.
2. Upload all contents of this folder to the repository root and commit them.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. The included CNAME file tells GitHub Pages to use protecfiresafety.co.uk.
6. In your domain provider's DNS settings, point the domain to GitHub Pages using GitHub's current documented DNS records. Also add www as a CNAME pointing to your GitHub Pages address.
7. Return to Settings > Pages, confirm the custom domain and enable Enforce HTTPS when available.

CONTACT FORM
